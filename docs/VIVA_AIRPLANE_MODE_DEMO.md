# Viva Demo — Airplane / Zero-WAN Proof (2 minutes)

**Goal:** Prove ClassDrop shares files with **no public internet**.

1. Host: disable Wi‑Fi uplink / unplug Ethernet (or enable Airplane Mode, then turn Wi‑Fi radio back on for hotspot only).  
2. ClassDrop → **Start Hotspot** (or Open Hotspot Settings → ON).  
3. Wait for banner **OFFLINE READY**.  
4. **Fix Firewall** once if not done.  
5. Phone: join teacher hotspot, **mobile data OFF**, scan **Wi‑Fi QR** (if shown) then **Room QR**.  
6. Upload a PDF from phone → host Live Transfers updates → second device downloads.  
7. Examiner sees: no cloud, no cellular path required, files on host disk only.

If hotspot will not start without internet: use Loopback adapter note in `OFFLINE_CHEAT_SHEET.md`, or phone-hotspot reverse mode (`PHONE_HOTSPOT_REVERSE_MODE.md`).
