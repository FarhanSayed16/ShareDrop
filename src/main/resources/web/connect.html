If your phone says No Internet, that is normal. Stay on the teacher Wi‑Fi.

Student steps

  1. Open Wi‑Fi settings and join the teacher hotspot (ask for the Wi‑Fi name/password).
  2. Turn OFF mobile data for a minute (stops the phone from using cellular instead of the hotspot).
  3. Open this page again, or type the URL shown on the host screen (usually http://192.168.137.1:8080).
  4. Enter the 6-digit room code and your name → Join.
