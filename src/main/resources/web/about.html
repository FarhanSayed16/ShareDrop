About ClassDrop

In the room, in the browser, off the cloud.

The Classroom Sharing Problem

In a lecture or practical lab, sharing files should be as effortless as passing a physical note. Yet students often resort to uploading multi-gigabyte assignment zip files or photos to external cloud storage (Google Drive, WeTransfer) only for classmates sitting three feet away to download them back across an overloaded campus internet connection.

ClassDrop solves this by turning one student's laptop into a temporary classroom drop box over local Wi-Fi or Windows Mobile Hotspot. No apps to install, no cloud relays, zero external data consumption.

Cloud Lockers vs. ClassDrop

Cloud Services (Google Drive / WeTransfer):

Upload to public cloud → Stored on third-party servers → Classmates download from cloud across internet.

ClassDrop (In-Room Server Hub):

Classmate uploads → Host laptop on port 8080 → Classmates stream directly over LAN/Hotspot → Host closes app, files are gone.
