ClassDrop Privacy

Local data boundaries and honest architectural claims.

Data Policy & Disclosures

  • No Cloud Storage: Files never leave your local room network in LAN or Hotspot mode.
  • Host Laptop Acts as Server: All uploads are temporarily staged on the host laptop's local disk (`data/` directory).
  • Session Expiry: When the host terminates the session or closes the ClassDrop application, all staged files are deleted and access tokens are invalidated.
  • Academic Audit History: For academic grading purposes, local MySQL records transfer audit metadata (filenames, sizes, device names, timestamps). Raw file contents are purged.
  • Transport Security Notice: Traffic over local Hotspot/LAN uses plain HTTP. Anyone connected to the same hotspot who has the 6-digit room code can access shared items.
